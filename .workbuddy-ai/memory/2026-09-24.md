# 2026-09-24

## Portfolio site redesign ("Nexus")

Redesigned the Lenovo Beast portfolio (`esports-playground`, Vite + React 18 + Tailwind 3 +
GSAP + framer-motion + Three.js) in place.

### What the site is
Single-page senior-dev portfolio. Section order (preserved): Hero → Projects → About →
Stack → Games → Contact → Footer, plus a 404 route. `projects.json` is the single source of
truth for the project catalogue, re-exported by `src/data/projects.js`.

### New files
- `src/three/backdrop.js` — interactive 3D constellation behind the whole page (core crystal +
  one node per section + dust). Drag to spin, hover to highlight, click node/label to navigate;
  camera dollies with scroll depth. Degrades gracefully if WebGL is unavailable.
- `src/components/Nav.jsx` — new sticky glass header (the site previously had NO navigation):
  scroll-spy, progress rail, auto-hide on scroll-down, mobile drawer, deep-link support.
- `src/components/Preloader.jsx`, `src/components/World.jsx` (rewritten to mount the
  constellation and project DOM labels from 3D node positions each frame).
- `src/hooks/useActiveSection.js` (scroll-spy + `scrollToSection`), `src/hooks/useReducedMotion.js`
  (`useReducedMotion`, `useInView`), `src/hooks/useTilt.js` (pointer-driven 3D tilt).
- `src/data/nav.js` — shared SECTIONS/SOCIALS list used by Nav, World and scroll-spy.
- `src/index.css` — full rewrite; every original utility kept (mini-games depend on
  `.game-overlay.active`, `.game-card`, etc.), plus `.panel`, `.tilt-*`, aurora, vignette,
  cursor-glow, nav, progress rail, boot veil.

### Fixes to existing behaviour
- `src/world.js`: `setupScene(canvas, getSize)` is now container-aware (desk world moved into
  the Games section); orbit controls ignore touch, and wheel zoom was removed because it
  hijacked page scrolling.
- `src/games/wireGames.js`: raycast NDC now derived from the canvas rect (not the window), and
  `userData.game` is resolved by walking up parent objects — clicking 3D game artifacts never
  worked before because the raycast reported child meshes.

### Test contracts that must keep passing (test/*.test.js)
- `Hero.jsx`: exactly one `const TerminalWindow3D`, rendered once as `<TerminalWindow3D />`,
  must contain `8+`, `47`, `12k+`.
- `World.jsx`: must render `<canvas id="canvas">`.
- `Games.jsx`: catalogue must list 'snake','breakout','racer','match3','launch'; must contain
  `data-game={game.name}` and the template ids `${name}Overlay|Canvas|Score|Status`.
- `App.jsx`: must render `World` and `Games`.
- `projects.json` shape + uniqueness; `src/data/projects.js` re-exports it verbatim.
